Primera versión que se actualiza desde el propio navegador.

- Actualizaciones integradas: Configuración → Acerca de ICARUS → Actualizaciones muestra la versión instalada, la última disponible, el estado y la última comprobación, con «Buscar actualizaciones», «Descargar actualización», «Actualizar y reiniciar» y la opción «Actualizar automáticamente». Cada versión se verifica con el manifiesto firmado y el SHA-256 de cada paquete.
- Windows: se instala sobre la versión actual sin desinstalar, conservando los datos; si el instalador falla, se restaura la versión anterior.
- Linux: AppImage que se actualiza solo y vuelve a la versión anterior si la nueva no arranca.
- Estilo Panorama (Edge): pestaña pegada a la barra, protocolo siempre visible, candado, Extensiones con ICARUS Shield, modo lectura, «Añadir a la página Nueva pestaña» y perfil personalizable con foto, nombre y color.
- Iconos de los sitios detectados automáticamente en pestañas, accesos directos, favoritos e historial.
