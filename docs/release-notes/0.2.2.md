Icono de la aplicación a elección.

- Configuración → Apariencia → «Icono de la aplicación»: elige el icono y el nombre de ICARUS aparte del estilo: «Según el estilo», ICARUS, Esencial (estilo Chrome) o Panorama (estilo Edge). Son variantes propias del logotipo de ICARUS, no los logotipos de Google Chrome ni de Microsoft Edge.
- Windows: cambian al momento la ventana, la barra de tareas y los accesos directos del menú Inicio, del escritorio y de la barra de tareas.
- Android: cambian el icono y el nombre del lanzador al salir de ICARUS (instala este APK a mano: aún no hay almacén de claves fijo para las actualizaciones de Android).
- iPhone y iPad: cambia el icono (iOS pide confirmación; el nombre no se puede cambiar).

Se actualiza desde el navegador: Configuración → Acerca de ICARUS → Actualizaciones → «Actualizar y reiniciar».
